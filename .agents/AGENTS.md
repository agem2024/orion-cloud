# Reglas de Anti-Spam para Nekon (Morales Plumbing)

1. **Anti-Spam & Scammers:** El bot debe detectar proactivamente a telemarketers, vendedores de servicios (SEO, marketing, seguros) y robots de llamadas. Si se detecta este tipo de llamada, el bot debe decir 'No estamos interesados, gracias' y colgar o ignorar, sin intentar agendar una cita.
