2. Introducción y Propósito

Este documento es la guía técnica y operativa oficial para administrar el ecosistema digital de Morales Plumbing. El propósito de este manual es garantizar que el equipo administrativo (Dueño, Dispatcher) comprenda y opere correctamente el Asistente Orion, gestione las citas automatizadas y mantenga el sistema estable.

Perfil del Usuario: Dirigido a Administradores y Personal de Soporte Interno. No se requieren conocimientos avanzados de programación para la operación diaria, pero sí seguimiento estricto de este protocolo.

3. Advertencias y Seguridad

Cumplimiento CCPA Estricto

La información almacenada en Firebase (Nombres, Teléfonos, Direcciones) está protegida bajo la Ley de Privacidad del Consumidor de California (CCPA). NUNCA exporte ni comparta estos datos fuera del entorno seguro (Render/Firebase).

Protección de Tokens

No altere el archivo serviceAccountKey.json ni comparta su TELEGRAM_BOT_TOKEN. Si sospecha que una credencial ha sido expuesta, contacte a soporte inmediatamente para rotar las llaves.

5. Instrucciones de Operación (Paso a Paso)

A continuación se detalla el flujo exacto de qué sucede y cómo debes actuar cuando un cliente agenda una cita desde la web.

Paso 1: El cliente envía el formulario

El cliente llena sus datos en la página web. El sistema previene el uso de la app de WhatsApp y envía silenciosamente los datos cifrados a Render.

Paso 2: Procesamiento y Respaldo

Orion asigna un ID único (ej. MP-4521) y hace un respaldo de la cita en Firebase Firestore de forma inmediata.

Paso 3: Notificación Multicanal

El cliente recibe un correo HTML profesional confirmando la recepción y sugiriendo el sistema "Hágalo Usted Mismo". Simultáneamente, el servidor despacha un Webhook a Telegram.

Paso 4: Acción del Administrador

Tu celular vibrará con un mensaje de Telegram. Debes leer el diagnóstico y los materiales sugeridos por la IA, y proceder a llamar al cliente o enviar al técnico.

6. Mantenimiento y Cuidado

  • Revisión Diaria: Ejecute el comando /status en Telegram al inicio del día para asegurar que la nube está operativa.
  • Limpieza de Logs: Cada fin de mes, el script de seguridad (`security_backup.py`) zipea los logs. Descargue estos archivos desde el panel de Render y libere espacio.
  • Actualización de Credenciales: Si se cambia la contraseña del correo `moralesplumbing026@gmail.com`, debe actualizar la variable de entorno `EMAIL_PASS` en el Dashboard de Render inmediatamente o los correos a clientes fallarán.

7. Guía de Solución de Problemas

Falla / Síntoma Causa Probable Solución Inmediata
No llegan notificaciones a Telegram Render entró en suspensión (Sleep) o Token inválido. Envíe el comando /start. Si no hay respuesta, reinicie el servicio web en el panel de Render.
El cliente no recibe el correo HTML Contraseña de Gmail cambiada o Bloqueo por SPAM. Revise la carpeta de enviados de Gmail. Actualice EMAIL_PASS en variables de entorno.
Error 500 al agendar en la web Firebase desconfigurado (ServiceAccount). Verifique que el archivo serviceAccountKey.json esté intacto en el servidor.
